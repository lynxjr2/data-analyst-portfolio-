## Retail sales performance

A retail case study examining revenue, gross profit and returns across four product categories and four Nigerian cities. The dataset contains simulated transactions from January–December 2025. Amounts are in Nigerian naira (NGN).

| Measure | Result |
| --- | --- |
| Clean transactions | 1,500 |
| Net revenue | ₦37,176,500 |
| Gross profit | ₦13,729,300 |
| Gross margin | 36.9% |
| Return rate | 8.2% |

Electronics contributes the most revenue. Beauty has the highest category gross margin. Fashion has the highest category return rate.

## Methods

The analysis includes duplicate checks, record validation, text standardisation, grouped sales and profit calculations, and monthly comparisons. The Excel workbook includes city and category filters and a monthly revenue chart.

Power BI query and measure files are included. The native Power BI report is planned.

The dataset is simulated, with the metric definitions and assumptions documented in the case study.
