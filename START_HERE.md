# Start here

This is your first portfolio version. It contains a website and a guided analysis project. The supplied results help you check your work; the next step is to understand, reproduce and extend the analysis.

## 1. Personalise the introduction

- [ ] Confirm your display name in `assets/profile.js`.
- [ ] Add your GitHub username. Leave the value as an empty string until you have one.
- [ ] Set `repositoryName` to the name you choose on GitHub.
- [ ] Add an email only if you want it displayed as a contact link.
- [ ] Read the introduction in `README.md`, `PROFILE_README.md` and `index.html`. Make it sound like you.

## 2. Understand the Excel analysis

- [ ] Open `projects/retail-sales/excel/Retail_Sales_Analysis.xlsx`.
- [ ] On Summary, confirm ₦37,176,500 net revenue, ₦13,729,300 gross profit and 1,500 transactions with both selectors set to All.
- [ ] Select Lagos and compare its revenue with the SQL city result: ₦16,136,725.
- [ ] Select Beauty and explain why the gross margin is 45.1%.
- [ ] Find a returned row on Sales and explain why its revenue, COGS and gross profit are zero.
- [ ] Explain why overall return rate is 123 ÷ 1,500, rather than the average of the twelve monthly percentages.

## 3. Run the SQL

- [ ] Follow `projects/retail-sales/sql/README.md`.
- [ ] Reproduce the overview and cleaning counts.
- [ ] Read the category and monthly growth queries.
- [ ] Change one query to answer your own question. Keep the original query and put your addition in a new file.

Suggested extension: Which products within Fashion have the highest return rates? Report counts beside rates so small samples are visible. The result cannot establish the reason for returns.

## 4. Build the Power BI report

- [ ] Follow `projects/retail-sales/power-bi/BUILD_GUIDE.md`.
- [ ] Create the Calendar relationship and DAX measures.
- [ ] Reconcile the headline cards with the expected results.
- [ ] Check that city and category slicers update every intended visual.
- [ ] Save the actual report as `projects/retail-sales/power-bi/Retail_Sales_Report.pbix`.
- [ ] Add real screenshots of your completed report. This starter does not contain a `.pbix` file or fabricated Power BI screenshots.

## 5. Add your own contribution

- [ ] Explain the cleaning choices in your own words.
- [ ] Add one original SQL question and its answer.
- [ ] Add a chart that supports that answer.
- [ ] Write one paragraph with the finding, the supporting figure and a limitation.
- [ ] Update project status and the portfolio About section to reflect what you actually completed.

## 6. Publish

- [ ] Open `index.html` locally and check both pages, dropdowns, downloads and phone layout.
- [ ] Follow the GitHub upload and Pages instructions in `README.md`.
- [ ] Confirm that the website URL works and all files download after upload.
- [ ] Pin the portfolio repository on your GitHub profile.

## Prepare to discuss it

Be ready to explain the business question, the grain of the data, the duplicate rule, the missing-value assumptions, why margin differs from profit, and why a higher return rate does not reveal its cause.
